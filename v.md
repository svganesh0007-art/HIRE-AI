Create a complete, functional, modern and responsive web application called:

"Intelligent Resume Analyzer"

PROJECT OBJECTIVE:
Build a simple and reliable resume analysis website that compares a candidate's resume against a Job Description (JD) and helps identify how well the resume matches the job requirements.

IMPORTANT PROJECT RULES:
1. DO NOT use any external packages.
2. DO NOT use any external libraries or frameworks.
3. DO NOT use any third-party APIs.
4. DO NOT use AI APIs, OpenAI APIs, Gemini APIs, Hugging Face APIs, or any cloud service.
5. All resume analysis and comparison logic must be implemented using only built-in programming language and browser features.
6. The application must work without internet connectivity after loading.
7. Do not use Bootstrap, React, Angular, Vue, Tailwind, jQuery, Chart.js, or any other third-party library.
8. Use only:
   - HTML
   - CSS
   - Vanilla JavaScript
   - Built-in browser APIs
9. The GitHub repository must contain the complete source code.
10. The application must be fully functional for demonstration.

CORE FUNCTIONALITY:

Create a single-page Resume Analyzer application.

The user should be able to:

1. Enter or upload a Job Description.
2. Enter or upload a Resume.
3. Click an "Analyze Resume" button.
4. The application should compare the resume content with the job description.
5. Generate a matching score.
6. Display matched skills/keywords.
7. Display missing skills/keywords.
8. Display resume strengths.
9. Display improvement suggestions.
10. Clearly show whether the candidate is a strong, moderate, or weak match.

ANALYSIS LOGIC:

Implement the complete analysis using Vanilla JavaScript.

STEP 1 — TEXT PREPROCESSING:
- Convert both resume and JD to lowercase.
- Remove unnecessary punctuation.
- Normalize spaces.
- Split text into words.
- Remove common stop words such as:
  the, a, an, and, or, is, are, to, of, in, for, with, on, from, by, as, at, be, this, that, etc.

STEP 2 — KEYWORD EXTRACTION:
Extract important words and phrases from the Job Description.

Identify:
- Technical skills
- Programming languages
- Frameworks
- Databases
- Tools
- Soft skills
- Job-related keywords

Since external NLP libraries are forbidden, implement keyword extraction using JavaScript logic such as:
- word frequency
- predefined common technical skill list
- phrase matching
- frequency-based scoring

Include a built-in list containing common skills such as:

Programming:
C, C++, Java, Python, JavaScript, TypeScript, SQL, HTML, CSS

Web:
React, Node.js, Express, Angular, Vue, REST API, API, Full Stack, Backend, Frontend

Database:
MySQL, MongoDB, PostgreSQL, Oracle, SQL Server

AI/ML:
Machine Learning, Deep Learning, Artificial Intelligence, NLP, Computer Vision, TensorFlow, PyTorch

Data:
Data Analysis, Data Science, Pandas, NumPy, Statistics, Power BI, Excel

Cloud/DevOps:
AWS, Azure, Docker, Git, GitHub, CI/CD, Linux

Other:
Communication, Leadership, Teamwork, Problem Solving, Time Management

The application should not blindly depend on this list. It should also extract frequent meaningful words from the JD.

STEP 3 — MATCHING:

Compare the extracted JD keywords/skills against the resume.

For every important keyword:
- If it exists in resume → MATCHED
- If it does not exist → MISSING

Support phrase matching where possible.

Example:

JD:
Python, SQL, Machine Learning, Git, Communication

Resume:
Python, SQL, Git, Communication

Result:
Matched:
Python
SQL
Git
Communication

Missing:
Machine Learning

STEP 4 — MATCH SCORE:

Calculate an overall percentage score.

Use a transparent scoring system.

Example:

Skill/keyword match = 70%
Experience/relevant content = 15%
Education/relevant qualification = 10%
Resume completeness = 5%

The exact calculation must be implemented in JavaScript and clearly explained in the UI.

Do NOT claim that the score is generated by AI.

Display:

Use score categories:

80–100:
"Strong Match"

60–79:
"Moderate Match"

Below 60:
"Weak Match"
